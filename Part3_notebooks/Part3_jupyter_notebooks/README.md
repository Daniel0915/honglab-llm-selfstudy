# 파트3 주피터 노트북

강의에서 본 트랜스포머의 부품과 실험을 직접 돌려 보는 노트북입니다.
강의 내용을 전부 담지는 않았습니다. 영상에서 본 결과를 확인할 수 있는 최소한의 예제만 넣었습니다.

| 노트북 | 해당 강의 | 실행 시간 | 메모리 |
|---|---|---|---|
| `01_어텐션계산.ipynb` | 트랜스포머의 구조 · 현대적 레시피 | 몇 초 | 300MB 이하 |
| `02_BPE토크나이저.ipynb` | 파이토치 구현 | 몇 초 | 100MB 이하 |
| `03_작은GPT만들기.ipynb` | 파이토치 구현 | 2분 안팎 | 1GB 이하 |
| `04_인컨텍스트러닝.ipynb` | 인컨텍스트 러닝 | 3분 안팎 | 600MB 이하 |

GPU는 필요 없습니다.

## 준비

- 파이썬 3.10 이상과 주피터가 필요합니다. 아나콘다를 설치했다면 둘 다 들어 있습니다.
- `01`과 `04`는 PyTorch와 matplotlib, `02`는 regex, `03`은 셋 모두 씁니다.
- `02`와 `03`은 「실습 자료 다운로드」 레슨에서 받은 실습 자료 중 `exp02_tinystories_Korean` 폴더를 씁니다. 이 폴더를 노트북 폴더 안으로 옮기면 그대로 돌아갑니다. 다른 곳에 있다면 노트북의 `EXP02` 경로를 그 폴더로 고치면 됩니다(`02`는 「실습 자료의 토크나이저」 칸, `03`은 첫 코드 칸).

```bash
pip install -r requirements.txt
```

PyTorch는 CPU 버전이면 충분합니다. 이미 설치돼 있다면 그대로 쓰면 됩니다.

## 실행

이 폴더에서 주피터를 실행하고 노트북을 번호 순서대로 엽니다. 메뉴의 Run All(모두 실행)을 누르면 위에서 아래까지 한 번에 돌아갑니다.

```bash
jupyter lab
```

실행 결과가 노트북에 저장돼 있어서 돌리지 않고 읽기만 해도 됩니다.

## 실습 자료에서 읽는 파일 (`02`, `03`)

| 파일 | 쓰는 곳 |
|---|---|
| `tokenizer/ko_tinystories_bpe_8k.json` | `02`, `03` — 어휘 8천 개짜리 한국어 동화용 BPE 토크나이저 |
| `tokenizer/ko_tinystories_bpe_16k.json` | `02` — 어휘 크기 비교 |
| `dataset/ko_tinystories/valid.txt` | `02` 어휘 크기 비교, `03` 훈련 루프 |
| `checkpoints/tiny_1ep.pt` | `03` — 노트북과 같은 크기로 GPU에서 끝까지 훈련한 모델 |
| `src/bpe.py`, `src/model.py` | `03` — 토크나이저 코드, 체크포인트 안의 설정 읽기 |

이 노트북 묶음에는 위 파일을 다시 넣지 않았습니다. 실습 자료에 이미 들어 있기 때문입니다.
`01`과 `04`는 데이터 파일 없이 돕니다.

## 강의와 다른 점

- `03`은 실습 자료의 가장 작은 모델(tiny, 약 530만 파라미터)과 같은 크기로 만듭니다. 강의 화면의 예시는 약 3천만 파라미터였습니다. 강의 화면의 QK-norm은 이 모델에 없습니다(실습 자료의 모델이 QK-norm 없이 훈련됐습니다).
- `04`의 인덕션 헤드 실험은 강의의 사전 문제 대신 단어 묶음이 반복되는 문제를 씁니다. 원리는 같지만 사전 문제는 CPU로 몇 분 훈련해서는 성공할 때도 있고 아닐 때도 있었습니다. 강의 실험의 원래 크기 코드는 실습 자료의 `exp04_icl_demos` 폴더에 있습니다.

## 결과가 조금 다르게 나올 때

모든 노트북은 난수 시드를 고정해 두었습니다. 같은 환경이면 저장된 결과와 똑같이 나옵니다.
PyTorch 버전이나 기기가 다르면 훈련 결과의 수치가 조금 달라질 수 있습니다. 특히 `04`에서 정확도가 뛰어오르는 시점은 앞뒤로 움직일 수 있습니다.
저장된 결과는 파이썬 3.12와 PyTorch 2.14(CPU)로 만들었습니다.
