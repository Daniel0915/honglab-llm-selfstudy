## 1. 통계적 언어 모델의 시작

가장 기본이 되는 통계적 언어 모델이 **N-그램**이고,
여기서 통계란 **각 글자가 몇 번 나타나는지를 세는 것**이다. (챕터2 퀴즈 4번)
이런 방식을 **카운트 기반 언어 모델**(count-based language model)이라 부르기도 한다.

데이터는 **국어사전**. 한국어에서 어떤 글자가 더 자주 쓰이는지 알고 싶으면
사전에서 각 글자의 출현 횟수를 세면 된다.

```
빈도 ▲
     │ ████████  이
     │ ███████   하
     │ ██████    다
     │ █████     기
     │ ████      사
     │ ███       자
     │ ██        리
     └────────────────▶ 글자
```

각 글자가 몇 번 나타나는지 센 값이 **빈도(frequency)**.

---

## 2. AI 사용 팁

| 관찰 | 내용 |
|---|---|
| **계획부터 세우도록 유도** | 「바로 해줘」가 아니라 **「어떻게 하면 좋을까」**라고 물으면 계획을 먼저 제안한다. 의도를 함께 주면 더 적절한 계획이 나온다 |
| **컨텍스트의 영향** | AI가 C 프로그램을 쓰자고 제안한 것은 앞서 C로 Hello World를 했던 컨텍스트가 남아 있어서다 |
| **AI의 사전 지식** | 「빈도」라는 한자어를 AI가 자연스럽게 이해하는 것은 뉴럴 모델이 **의미가 비슷한 단어들의 관계**를 잘 잡기 때문. NLP에서 **단어 임베딩**(word embedding)이라 한다 |
