## 한 줄

**현대 LLM의 핵심 아이디어는 1948년 섀넌에서 출발한다.**
그래서 가장 단순한 형태(N-그램)부터 쌓아 올리는 것이 효율적인 학습 방법이다.

---

## 1. 출발점 — 섀넌 1948

클로드 섀넌, *A Mathematical Theory of Communication*.
**마르코프 체인을 언어에 적용**하여
「앞에 나온 글자를 바탕으로 다음 글자의 확률을 결정하는 방식」을 수학적으로 정리했다.

현대 LLM의 핵심 훈련 방식인 **다음 토큰 예측**(next token prediction)이
여기서 출발한다. (챕터1 퀴즈 4번)

### 문맥이 예측을 좁혀주는 과정

```
"나는 오늘 학교에 ?"
    간다 20% | 안 갈래 50% | 다녀왔어 30%
    → 짧은 문맥으로도 추정은 되지만 확신할 수 없음

"나는 감기에 걸렸어. 나는 오늘 학교에 ?"
    → 문맥이 추가되면 예측의 확신이 높아진다
```

이 그림 하나가 **왜 컨텍스트 길이가 모델의 성능 지표인지**를 설명한다.
그리고 파트2의 첫 질문(「문맥을 길게 보면 왜 오히려 망가지는가」)이
정확히 이 그림의 반대편에서 시작한다.

## 2. 연표

| 시기 | 사건 | 내용 |
|---|---|---|
| **1948** | 정보 이론의 시작 | 섀넌이 마르코프 체인으로 언어의 통계적 구조를 정리 |
| 1950s–70s | 규칙 기반 시도 | 문법 규칙을 프로그래밍하는 방식. 많은 노력에도 실용적 결과 없음 |
| **1970s 후반** | 통계적 언어 모델 | Jelinek의 IBM 팀이 음성 인식에 통계적 방법 도입, 이후 n-gram 적용. **규칙 → 데이터 기반 전환** |
| 2003 | 뉴럴 언어 모델 | Bengio et al. — 뉴럴 네트워크로 언어 모델을 만드는 방법 |
| **2017** | 트랜스포머 | *Attention Is All You Need*. 이후 발전 속도가 급격히 빨라짐 |
| 2022 | LLM 대중화 | ChatGPT 공개(2022.11). 규모를 키우면 성능이 오른다는 접근이 대세 |
| 2024– | AI 에이전트 시대 | 강화학습으로 도구 사용 능력 향상 |

**가장 중요한 전환점은 1970년대 후반이다.** (챕터1 퀴즈 6번)
「규칙을 찾아서 프로그래밍한다」에서
「데이터에서 통계를 뽑아낸다」로 바뀐 것 — 지금까지 이어지는 패러다임이다.

## 3. 파트1의 목표

**N-그램을 직접 구현하여 통계적 언어 모델의 기본 원리를 이해하는 것.**
(챕터1 퀴즈 10번)

> LLM을 만드는 기술은 더 이상 비밀이 아니다.
> 코딩 AI 덕분에 직접 만들면서 배울 수 있는 시대가 되었다.

---

## 4. [참고] 「통계적 언어 모델」이라는 용어

강의가 직접 달아둔 단서. 용어가 문헌마다 다르다.

- N-그램은 통계적 언어 모델의 **한 종류**로 보는 것이 일반적이다.
  통계적 언어 모델에는 그 외에도 다양한 기법이 있다.
- 빈도를 세는 방식의 언어 모델을 **카운트 기반 언어 모델**
  (count-based language model)이라 부르기도 한다.
- 뉴럴 언어 모델을 통계적 언어 모델로 보는 관점도 있고,
  반대로 일부 문헌(Minaee et al., 2024)은 **SLM**(Statistical Language Model)을
  뉴럴 언어 모델과 **분리해서** 쓴다.

이 강의는 **규칙 기반 → 데이터 기반이라는 역사적 흐름**을 이해하고
이후 뉴럴 방식을 배울 기초를 확보하기 위해 카운트 기반 N-그램을 직접 구현한다.
