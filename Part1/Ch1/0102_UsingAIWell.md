## 한 줄

**AI는 주사위를 굴리는 시스템이고, 기억이 없다.**
그래서 잘 쓰는 법은 「더 세게 조르기」가 아니라 **컨텍스트를 설계하기**다.

---

## 1. 인간의 지능 vs 인공지능

| | 인간 | LLM |
|---|---|---|
| 신체 | **체화된 인지**(embodied cognition) — 신체·환경 상호작용 속에서 형성 | **신체 없음**(disembodied) |
| 기억과 사고 | 하나로 통합 | **분리되어 있음** |
| 학습과 사용 | 동시에 일어남 | **분리 가능** |
| 복제 | 불가능 — 각자 직접 경험해야 함 | 한 곳에서 학습 후 **사본을 대규모 배포** |

가장 결정적인 차이는 마지막 두 줄이다 —
**학습과 사용을 떼어낼 수 있다는 것.** (챕터1 퀴즈 1번)
데이터센터 한 곳에서 훈련한 뒤 사본을 전 세계에 뿌려 쓸 수 있다.
인간에게는 불가능한 일이고, 이것이 AI의 경제성을 만든다.

**아직 인간의 영역** — 순간적인 직관과 깊이 있는 통찰.
무엇을 만들지 방향을 정하고 결과물을 판단하는 일. (챕터1 퀴즈 8번)

## 2. AI는 주사위를 굴리는 시스템

확률이 두 번 들어간다.

**훈련할 때**
- 가중치 초기화 (Xavier / He initialization) — 난수로 시작
- 확률적 경사 하강법 (SGD)

**사용할 때**
- temperature sampling · top-k · top-p(nucleus) — 확률적 디코딩
- 그래서 **같은 입력에도 매번 다른 결과**가 나온다 (non-deterministic)

### 그래서 어떻게 쓰나

> 좋은 결과가 나올 때까지 같은 입력을 단순 반복하는 것보다
> **컨텍스트를 개선하는 쪽**이 효과적이다.

단, 반복이 항상 무의미한 것은 아니다 —
같은 프롬프트를 여러 번 돌린 뒤 **다수결**로 답을 고르는
**Self-Consistency** (Wang et al., 2022) 는 효과가 입증되어 있다.
「반복은 쓸모없다」가 아니라 **「맹목적 반복 대신 구조화된 반복」**이 요점.

## 3. 컨텍스트를 다스리는 자가 AI를 다스린다

| 단계 | 내용 |
|---|---|
| 기억이 없다 | LLM은 무상태(stateless). 기억처럼 보이는 것은 매번 과거 대화를 다시 넣어주는 것 |
| 컨텍스트 | 의도를 정확히 전달하려면 **이유와 요구사항을 구체적으로 함께** 요청해야 한다 |
| 프레임워크 설계 | 숙련자는 컨텍스트를 직접 관리하는 것을 넘어 **AI가 스스로 컨텍스트를 구성하도록 설계**한다 |

세 번째 줄이 실무에서 가장 멀리 가는 이야기다.
프롬프트를 매번 잘 쓰는 사람보다, **잘 쓸 수밖에 없는 구조를 만든 사람**이 이긴다.

### Lost in the Middle (Liu et al., 2024)

LLM은 프롬프트의 **처음과 끝은 잘 쓰고 중간은 놓친다.**

```
처음 ─ 지시          "다음 문서를 요약해줘"            ← 잘 읽음
중간 ─ 긴 참고 문서   제1장 서론… (수천 단어) …        ← 놓치기 쉬움
끝   ─ 핵심 질문      "특히 결론 부분을 강조해줘"       ← 잘 읽음
```

**실무 규칙: 중요한 것은 앞이나 뒤에 둔다.**

### 용어 두 개

| 용어 | 범위 |
|---|---|
| **컨텍스트 엔지니어링** | 어떤 정보를 어떻게 제공할지 **시스템 수준**에서 설계 |
| **하네스 엔지니어링** | 환경 · 제약조건 · **피드백 루프 전체**를 설계 |

프롬프트 엔지니어링 → 컨텍스트 엔지니어링 → 하네스 엔지니어링 순으로
다루는 범위가 넓어진다. 뒤로 갈수록 「말을 잘 고르는 일」에서
「시스템을 짜는 일」로 옮겨간다.

## 4. 참고 자료 (강의 제시)

- Scaling Laws for Neural Language Models (Kaplan et al., 2020) — 모델 규모와 성능의 관계
- Embodied Cognition (Wikipedia) — 인간 인지와 신체의 관계
- Stochastic Gradient Descent (IBM) — 훈련의 확률적 특성
- LLM Temperature (IBM) — 추론의 확률적 특성
- Self-Consistency (Wang et al., 2022) — 다수결 기반 추론 정확도 향상
- Lost in the Middle (Liu et al., 2024) — 프롬프트 내 정보 위치의 영향
- Context Engineering for AI Agents (Anthropic)
- Harness Engineering (OpenAI, 2026)
