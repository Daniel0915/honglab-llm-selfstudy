출발점
클로드 섀넌은 1948년 논문 A Mathematical Theory of Communication에서 마르코프 체인을 언어에 적용하여 "앞에 나온 글자를 바탕으로 다음 글자의 확률을 결정하는 방식"을 수학적으로 정리했습니다.
현대 LLM과의 연결
현대 LLM의 핵심 훈련 방식인 다음 토큰 예측(next token prediction)이 이 아이디어에서 출발합니다. 문맥(context)이 많을수록 다음에 올 내용의 확률을 더 정확하게 추정할 수 있습니다.

접근 방식
현대 LLM은 복잡하지만 핵심 아이디어는 섀넌의 1948년 논문까지 거슬러 올라갈 수 있습니다. 가장 단순한 형태에서 출발하여 하나씩 쌓아 올라가는 것이 효율적인 학습 방법입니다.
파트 1의 목표
N-그램(n-gram)을 직접 구현하여 통계적 언어 모델의 기본 원리를 이해하는 것입니다. 여기서부터 시작하여 현대적인 AI 에이전트까지 단계별로 만들어 나갑니다.

LLM을 만드는 기술은 더 이상 비밀이 아닙니다.
코딩 AI의 발전 덕분에 직접 만들면서 배울 수 있는 시대가 되었습니다.

[참고] "통계적 언어 모델"이라는 용어에 대해
N-그램은 통계적 언어 모델의 한 종류로 보는 것이 일반적이며 통계적 언어 모델에는 그 외에도 다양한 기법이 존재합니다. N-그램처럼 빈도를 세는 방식의 언어 모델을 카운트 기반 언어 모델(count-based language model)이라고 부르기도 합니다.
뉴럴 언어 모델을 통계적 언어 모델로 보는 관점도 존재하고 반대로 일부 문헌(Minaee et al., 2024)에서는 SLM(Statistical Language Model)이라는 용어를 뉴럴 언어 모델과 분리하여 사용하기도 합니다.
이 강의에서는 규칙 기반에서 데이터 기반으로의 전환이라는 역사적 흐름을 이해하고 이후 뉴럴 네트워크 방식의 언어 모델을 학습할 수 있는 기초를 확보하기 위해 카운트 기반 N-그램 모델을 직접 구현합니다.
