[안내] 퀴즈는 기억을 되살려보는 정도로 가볍게 활용하시면 됩니다.
정답과 설명은 아래 "정답/설명"을 클릭하면 보실 수 있습니다.
뒤에 나올 내용들이 미리 나오는 경우는 "눈치껏" 맞출 수 있는 문제들입니다.

1) 글자 빈도(frequency)를 확률로 변환하는 방법은?
A각 글자의 빈도에 로그를 취한다
B각 글자의 빈도를 제곱한다
C각 글자의 빈도를 전체 빈도의 합으로 나눈다
D빈도가 가장 높은 글자를 1로, 나머지를 0으로 설정한다
정답/설명정답: C
설명: 각 글자의 빈도를 전체 빈도의 합으로 나누면 확률이 됩니다. 예를 들어 전체 글자가 100개이고 그 중 "다"가 5번 나왔다면, "다"가 나올 확률은 5/100 = 5%가 됩니다.

2) 유니그램이 각 글자의 빈도를 세는 것이라면, 바이그램(bigram)은 무엇을 세는 것인가?
A두 글자 연속 조합의 빈도를 세는 것
B한 글자씩 빈도를 두 번 세는 것
C단어 전체의 빈도를 세는 것
D세 글자 연속 조합의 빈도를 세는 것
정답/설명정답: A
설명: 유니그램이 "어떤 글자가 많이 나오는가"를 세는 것이라면, 바이그램은 "어떤 글자 다음에 어떤 글자가 많이 오는가"를 세는 것입니다.
예) "나는 나비"라는 텍스트가 있을 때
유니그램: "나" 2번, "는" 1번, "비" 1번
바이그램: "나→는" 1번, "는→나" 1번, "나→비" 1번
따라서 "나" 다음에 올 글자를 고를 때 "는"과 "비"가 각각 50% 확률이 됩니다. 이렇게 앞 글자를 보고 다음 글자를 결정하는 것이 바이그램의 핵심입니다.

3) 통계적 언어 모델에서 텍스트를 생성할 때 확률에 따라 글자를 선택하는 데 사용하는 것은?
A해시 함수
B정렬 알고리듬
C암호화 키
D난수(random number)
정답/설명정답: D
설명: 확률 분포에 따라 글자를 생성할 때 난수를 사용합니다. 컴퓨터가 주사위를 굴리듯이 랜덤 넘버를 이용해서 글자를 선택하면, 확률이 높은 글자가 더 자주 나오고 확률이 낮은 글자는 덜 나오게 됩니다.

4) 강의에서 말하는 "통계"란 실제로 무엇을 하는 것인가?
A복잡한 수학 공식을 풀어내는 것
B글자가 몇 번 나타나는지 개수를 세는 것
C뉴럴 네트워크를 훈련시키는 것
D문법 규칙을 프로그래밍하는 것
정답/설명정답: B
설명: 여기서 말하는 통계는 각 글자가 몇 번 나타나는지를 세는 것입니다. 예를 들어 국어사전에서 한글 글자들이 각각 얼마나 자주 나타나는지를 세어 보는 것이 통계의 시작입니다. 이처럼 빈도를 세어서 확률을 구하는 방식의 언어 모델을 count-based language model이라고 부르기도 합니다.

5) n-gram 모델에서 n 값을 높이면 나타나는 현상은?
A생성 결과가 더 무작위해진다
B처리 속도가 빨라진다
C필요한 데이터의 양이 줄어든다
D생성된 텍스트가 더 그럴듯해지고, 원본 데이터와 일치할 확률이 높아진다
정답/설명정답: D
설명: n 값을 높일수록 더 긴 패턴을 학습하므로 생성 결과가 더 자연스러워집니다. 실습에서 바이그램(2) → 트라이그램(3) → 4그램 → 5그램으로 갈수록 사전에 실제로 존재하는 단어를 만들어낼 확률이 높아졌습니다.

6) 확률이 가장 높은 글자 하나만 반복적으로 선택하면 어떤 결과가 나오는가?
A같은 글자만 반복되는 결과가 나온다
B가장 자연스러운 문장이 생성된다
C완전히 무작위한 글자가 나온다
D오류가 발생하여 실행이 중단된다
정답/설명정답: A
설명: 유니그램(한 글자 빈도)만 가지고 있는 상황에서 가장 확률이 높은 글자만 선택하면, 매번 같은 글자가 나옵니다. 예를 들어 "다"가 가장 높으면 '다다다다다'만 출력됩니다. 이것이 난수를 사용한 확률적 샘플링이 필요한 이유입니다.

7) n-gram으로 문장을 생성할 때, 단어가 아닌 문장을 만들기 위해 추가로 고려해야 하는 것은?
A대문자와 소문자를 구분하는 것
B문장의 최대 길이를 제한하는 것
C공백과 구두점도 글자로 취급하는 것
D글꼴(font)의 종류
정답/설명정답: C
설명: 단어 생성에서는 공백이 필요 없었지만, 문장을 생성하려면 단어 사이의 빈칸이 있어야 합니다. 공백과 구두점도 하나의 글자로 취급하여 n-gram 통계에 포함시키면 자연스러운 문장 구조를 만들어낼 수 있습니다.

8) 한국어에서 단어 단위 n-gram을 만들 때, 영어처럼 공백으로 단순히 나누면 생기는 문제는?
A처리 속도가 너무 느려진다
B조사가 붙어서 같은 단어가 다른 단어로 취급되어 어휘가 너무 많아진다
C공백이 없는 문장이 많아서 나눌 수 없다
D영어와 글자 수가 달라서 오류가 발생한다
정답/설명정답: B
설명: 한국어는 교착어이기 때문에 "학교가", "학교를", "학교는", "학교에서"가 전부 다른 단어로 취급됩니다. 이렇게 되면 어휘가 너무 많아져서 통계가 제대로 작동하기 어렵습니다. 그래서 형태소 분석기를 사용하여 "학교"와 "에"를 분리해주는 과정이 필요합니다.

9) 형태소 분석기의 역할은?
A문장의 문법 오류를 자동으로 수정한다
B텍스트를 의미를 가진 최소 단위(형태소)로 분리한다
C글자의 빈도를 자동으로 세어준다
D문장을 다른 언어로 번역한다
정답/설명정답: B
설명: 형태소 분석기는 텍스트를 의미를 가진 최소 단위로 분리합니다. 예를 들어 "반갑습니다"를 "반갑"과 "습니다"로 쪼개줍니다.

10) AI에게 같은 질문을 두 번 했을 때, 결과는 어떻게 되는가?
A항상 동일한 결과가 나온다
B두 번째부터는 이전 답변을 기억하여 보완된 답을 준다
C내부적으로 난수를 사용하기 때문에 매번 다른 결과가 나올 수 있다
D같은 질문은 캐시되어 더 빠르게 동일한 답이 나온다
정답/설명정답: C
설명: LLM은 내부적으로 난수를 사용하여 대답을 생성합니다. 그래서 똑같은 입력을 넣어도 그때그때 다른 결과가 나올 수 있습니다.
