통계적 언어 모델의 시작
통계 = 개수 세기
가장 기본이 되는 통계적 언어 모델은 N-그램(n-gram)입니다. 여기서 통계란 각 글자가 몇 번 나타나는지를 세는 것입니다. 이런 방식의 언어 모델을 카운트 기반 언어 모델(count-based language model)이라고 부르기도 합니다.
데이터: 국어사전
한국어에서 어떤 글자가 더 자주 사용되는지 알고 싶다면 국어사전 데이터에서 각 글자의 출현 횟수를 세면 됩니다.

AI 사용 팁
계획부터 세우도록 유도
AI에게 바로 실행하라고 하지 않고 "어떻게 하면 좋을까"라고 물으면 계획을 먼저 제안합니다. 의도를 함께 전달하면 더 적절한 계획을 세워줍니다.
컨텍스트의 영향
AI가 C 프로그램을 작성하자고 제안한 것은 앞서 C언어로 Hello World를 진행했던 컨텍스트가 남아 있었기 때문입니다.
AI의 사전 지식
빈도라는 한자 용어를 AI가 자연스럽게 이해하는 것은 뉴럴 네트워크 기반 모델이 유사한 의미를 가진 단어들의 관계를 잘 파악하기 때문입니다. 이를 NLP에서는 단어 임베딩(word embedding)이라고 합니다.
