## 공개 전에 해 둘 것

### 1. 챕터 7을 끝내기

`0804_PEFT_LoRA` 는 `0703_FullFineTuning` 에서 계산한 VRAM 표를 전제로 합니다.
「7B 전체 미세 조정 = 98GB」를 직접 계산해 보지 않으면 LoRA가 무엇을 아끼는지 와닿지 않습니다.

### 2. 챕터 7이 남긴 질문 세 개

**Q1. 전체 미세 조정은 왜 비싼가?**
→ 가중치(2P) + 그래디언트(2P) + 옵티마이저 상태(8P). 뒤의 둘이 전체의 80%입니다.
   LoRA는 **이 둘을 거의 0으로** 만듭니다. 원본은 얼리고, 끼워 넣은 작은 행렬에만 그래디언트를 겁니다.

**Q2. 페르소나는 왜 RLVR로 못 하는가?**
→ 강화학습의 조건은 「추론 과제인가」가 아니라 **「코드로 채점되는가」** 입니다.
   정답 대조·테스트 통과·JSON 스키마는 채점기를 짤 수 있습니다.
   **말투와 인격은 못 짭니다.** 그래서 페르소나는 SFT와 선호 정렬(DPO) 쪽 일입니다.
   → `../Ch7/0701_TrainingPipeline.ipynb` 2·3절

**Q3. 합성 데이터의 함정은?**
→ 모델이 만든 데이터는 **그 모델의 편향과 오류를 그대로 물려받습니다.**
   (챕터7 퀴즈 17번) 페르소나 데이터는 거의 전부 합성일 수밖에 없어서,
   이 문제가 챕터 8의 중심 주제가 될 가능성이 큽니다.
