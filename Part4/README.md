## 이 파트의 한 문장

> **형식은 미세 조정으로, 능력은 사전훈련으로.**

- **바뀌는 것** = 대답하는 **형식**. 묻는 말에 답하고, 다 쓰면 멈추고, 시킨 일의 모양을 갖추는 것.
- **바뀌지 않는 것** = 대답에 담기는 **내용**. 지식·추론·계산은 사전훈련에서 이미 정해졌습니다.

그래서 지시 데이터를 늘려도 모르는 것을 알게 만들 수는 없습니다.
당장 필요한 지식은 **넣어주는**(RAG) 쪽이 현실적입니다.

## 실행 방법

Part2/Part3 는 torch 만으로 돌아갔지만, Part4 는 실제 사전학습 모델을 불러오므로
huggingface 스택이 필요합니다. **Python 3.11 환경(`.venv311`)** 을 쓰세요 —
최신 transformers 가 3.9 를 버렸습니다.

```bash
cd ~/git/honglab-llm-selfstudy
./.venv311/bin/pip install -r Part4/requirements.txt
./.venv311/bin/jupyter lab Part4
```

**transformers 없이도 전부 돌아갑니다.** 설치돼 있지 않으면
`chat.py` 의 `ByteTokenizer`(UTF-8 바이트 = 토큰)로 자동 대체되고,
손실 마스킹·배치 구성·훈련 루프의 동작은 **똑같이** 확인됩니다.
토큰 수만 실제보다 훨씬 많아집니다.

맥 M1 8GB 에서 `0703` 2절까지 **2~3분**이면 끝납니다.
3절(실제 베이스 모델)은 `RUN_REAL = True` 로 바꾸면 되지만,
[`Ch7/0704`](Ch7/0704_SFT_RunPod.md) 를 따라 GPU에서 돌리는 쪽을 권합니다.

## 설계 원칙 (Part2/Part3 와 동일)

**1. 모든 주장은 실행해서 확인합니다**

- 「가린 토큰도 모델은 읽는다」 → 인과 어텐션을 달고 **가린 위치의 그래디언트를 출력**합니다 (`0701` 1절)
- 「마스킹 없이 배우면 질문까지 지어낸다」 → 두 모델을 훈련해 **0/8 vs 8/8** 로 셉니다 (`0702` 3절)
- 「종료 토큰을 빼면 안 멈춘다」 → **17토큰에 멈춤 vs 상한 80토큰에서 잘림** (`0702` 4절)
- 「온도는 품질이 아니라 무작위성」 → **엔트로피와 멈춤 비율**로 잽니다 (`0703` 4절)

**2. 실패와 한계를 숨기지 않습니다**

`0703` 의 장난감 모델은 6건에 과적합해서 온도를 3.0까지 올려야 흔들립니다.
셀이 그 사실을 **직접 출력합니다.** 숨기고 「보세요 됩니다」라고 하지 않습니다.

**3. 작게 먼저 돌립니다**

`0703` 2절은 랜덤 초기화한 초소형 모델로 **3절과 완전히 같은 코드**를 검증합니다.
큰 모델에서 바로 시작하면 오타 하나 찾는 데 수십 분이 듭니다. 실무 순서 그대로입니다.

```python
render_chatml(messages, add_generation_prompt)  # 대화 -> ChatML 문자열
build_sft_example(tok, messages, mask_prompt)   # -> (input_ids, labels)  손실 마스킹
preview_mask(tok, ex)                           # 가린 토큰을 ░ 로 그려 보기
collate(batch, pad_id)                          # 패딩 라벨 = IGNORE_INDEX
split_long_conversation(msgs, tok, max_len)     # 완결된 문답 경계에서 쪼개기
```
